# 🗂 OrdersDashboard — Дашборд заказов и напоминания

Плагин для [FunPay Cardinal](https://github.com/sidor0912/FunPayCardinal) **v0.1.17+**

Дашборд активных заказов в Telegram + автоматические напоминания покупателям
«подтвердите заказ».

## Возможности

- 📋 **Дашборд активных заказов** — все незакрытые заказы с возрастом
  («оплачен 5 ч. 23 мин. назад»), самые старые сверху.
- 🗂 **Карточка заказа** — лот, покупатель (ссылка на профиль), цена, количество,
  время оплаты (МСК), время выдачи и сколько напоминаний уже отправлено.
- **Действия в 1 клик:**
  - 💬 **Напомнить сейчас** — отправить покупателю напоминание в чат заказа;
  - ↩️ **Возврат средств** — оформить возврат (с подтверждением);
  - 🔗 **Заказ на FunPay** — открыть страницу заказа.
- ⏳ **Авто-напоминания** — если заказ оплачен (или товар выдан автовыдачей)
  больше N часов назад (по умолчанию 12) и покупатель не подтвердил заказ,
  плагин сам отправит вежливое напоминание в чат заказа:
  - таймер считается **от момента выдачи** для автовыдачи (событие POST_DELIVERY) —
    напоминание не придёт раньше, чем покупатель получил товар;
  - лимит напоминаний на заказ (по умолчанию 1);
  - **исключения по подстрокам** в названии лота (например, «аренда» — там
    подтверждать раньше времени не нужно);
  - настраиваемый шаблон с переменными `$username`, `$order`, `$lot`.
- 🔔 Владелец получает уведомление о каждом отправленном напоминании и возврате.
- 💾 Состояние (отправленные напоминания, времена выдачи) переживает рестарт;
  записи о закрытых заказах автоматически чистятся.

## Установка

Скопируйте `orders_dashboard.py` в папку `plugins/` и перезапустите Кардинала:

```bash
cd /home/fpc/FunPayCardinal
wget https://raw.githubusercontent.com/yungspiderq/FPC-OrdersDashboard/main/orders_dashboard.py -O plugins/orders_dashboard.py
sudo systemctl restart FunPayCardinal@fpc
```

или отправьте файл боту в Telegram → `🔌 Плагины` → `➕ Добавить плагин`.

## Использование

1. Команда **`/orders`** (или `⚙️ Настройки` на странице плагина).
2. Главное меню показывает: сколько активных заказов, сколько «висят» дольше
   заданной задержки, статус авто-напоминаний.
3. **📋 Активные заказы** → нажмите на заказ → карточка с действиями.
4. Настройки авто-напоминаний — кнопки главного меню:

| Кнопка | Действие |
|---|---|
| 💬 Авто-напоминания: ВКЛ/ВЫКЛ | Включить/выключить автоматическую отправку |
| ⏳ Задержка: 12 ч. | Через сколько часов после оплаты/выдачи напоминать (1–168) |
| 🔁 Макс. напоминаний: 1 | Лимит напоминаний на один заказ (1–10) |
| ⏱ Интервал: 300с | Как часто проверять заказы (60–3600 сек.) |
| 📝 Текст напоминания | Шаблон: `$username`, `$order`, `$lot` |
| 🚫 Исключения | Подстроки названий лотов, которым не напоминать (по строке на значение, `-` для очистки) |

### Шаблон напоминания по умолчанию

```
Здравствуйте, $username! 👋
Ваш заказ #$order (лот: $lot) ожидает подтверждения.
Если вы всё получили — подтвердите, пожалуйста, выполнение заказа.
Если возникли вопросы или что-то не так — напишите мне в этот чат, обязательно поможем!
```

## Важно знать

- Время оплаты заказов FunPay отображает **по Москве (UTC+3)** — плагин это учитывает
  при расчёте возраста заказа.
- Возврат средств оформляется через официальный механизм FunPay (`orders/refund`) —
  действие необратимо, поэтому есть подтверждение.
- Авто-напоминания отправляются от имени вашего аккаунта в чат заказа; учтите
  флуд-лимиты FunPay (плагин шлёт не чаще одного напоминания на заказ).
- Настройки: `storage/plugins/orders_dashboard/settings.json`.

## Состав репозитория

- `orders_dashboard.py` — плагин (класть в `plugins/`).
- `tests_plugin_orders_dashboard.py` — тесты (46 проверок на моках: авто-напоминания,
  таймер от выдачи, исключения, пагинация заказов, чистка состояний, весь Telegram-UI,
  возвраты, настройки). Запуск из корня FunPayCardinal:
  ```bash
  cp tests_plugin_orders_dashboard.py /path/to/FunPayCardinal/
  cd /path/to/FunPayCardinal && pip install -r requirements.txt && python3 tests_plugin_orders_dashboard.py
  ```
